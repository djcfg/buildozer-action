# Помощник ППУ — автономный Android-просмотрщик

Приложение на Kivy, повторяющее структуру меню Telegram-бота из `../main3.py`.
Читает те же Google Docs / Sheets / Drive **напрямую, без Telegram**, и работает
офлайн: все тексты и таблицы держатся в локальном кэше телефона.

`main3.py` и весь код бота не изменялись — это отдельный проект в своей папке.

## Возможности

- **Техника / Оборудование / ВКС / МКСС** — те же разделы и те же документы, что у бота.
- **ТТХ**, **Прочие сведения (FAQ)**, **Сети**, **Ресурсы**, **Настройки**, **Общие сведения**.
- **Телефонные справочники** — тап по номеру открывает системный номеронабиратель (`ACTION_DIAL`,
  разрешение `CALL_PHONE` не требуется).
- **Фото/Схемы** — список файлов из папки Drive; картинка открывается с pinch-zoom, PDF
  отдаётся системному просмотрщику.
- **Полная синхронизация в одну кнопку** — подтягивает все тексты и таблицы (см. «Кэширование»).
- **Экран настроек** — списки техники, названия документов и таблиц, путь к `credentials.json`.
  Меняются на телефоне, пересобирать APK не нужно.
- **Импорт из `.env`** — можно вставить текст боевого `.env` бота и получить те же списки.

├── buildozer.spec          # сборка APK (только Linux / WSL2)
├── requirements.txt        # зависимости для десктоп-отладки

├── tools/make_icons.py

│   ├── storage.py          # офлайн-кэш (JSON + папка cache/media)
│   ├── google_api.py       # Docs/Sheets/Drive через requests (без gspread и httpx)
│   ├── parsing.py          # FAQ, таблицы, контакты
│   ├── runner.py           # фоновые задачи + возврат результата в UI-поток
│   ├── service.py          # кэш-первый слой данных, синхронизация, кэш медиа

    └── ui_smoke.py         # проход по всем экранам + скриншоты на десктопе

## Быстрый старт на десктопе (отладка)

Нужен Python 3.10–3.12 (на 3.14 колёс Kivy нет).

```powershell
cd d:\Qoder\ppu_bot_TG_only
py -3.12 -m venv .venv_kivy_test
.\.venv_kivy_test\Scripts\python.exe -m pip install -r ppu_kivy_app\requirements.txt
cd ppu_kivy_app
.\..\.venv_kivy_test\Scripts\python.exe main.py
```

Без `credentials.json` приложение запускается и показывает всё, что уже лежит в кэше;
при любой попытке синхронизации напишет статусом «credentials.json не настроен».

### Проверки

```powershell
.\..\.venv_kivy_test\Scripts\python.exe tests\smoke_test.py   # ядро, сеть не нужна
.\..\.venv_kivy_test\Scripts\python.exe tests\ui_smoke.py     # все экраны + tests/screenshots/
```

## Данные и доступ

1. В Google Cloud включите **Google Docs API**, **Google Sheets API**, **Google Drive API**.
2. Создайте Service Account, скачайте `credentials.json`.
3. Дайте Service Account доступ **только на чтение** к документам, таблице `ppu_info`
   и папкам со схемами (расшарить как «доступен по ссылке / читать» или по e-mail аккаунта).
4. В приложении: ⚙ Настройки → «Доступ к Google (service account)» →
   «📂 Выбрать credentials.json на устройстве» → «💾 Сохранить настройки».
   Файл копируется во внутреннюю папку приложения.

Названия документов и листов совпадают с ботом: `ТТХ <item>`, `Прочие <item>`,
листы `Сети_<item>`, `Ресурсы_<item>`, `Настройки_<item>`, папки Drive по названиям единиц техники.

## Кэширование (автономная работа)

- **Тексты и таблицы** — полностью. Кнопка «🔄 Полная синхронизация» (главный экран или
  нижняя панель) обновляет всё: общие сведения, 4 телефонных справочника, ТТХ и FAQ каждой
  единицы, сети/ресурсы/настройки, списки файлов схем. Прогресс — статусной строкой.
  После этого приложение работает без сети неограниченно.
- **Фото и PDF** — кэшируются по мере открытия (первый тап — скачать, дальше — с телефона).
  Отдельная кнопка «⬇ Кэшировать все файлы (N)» на экране «Фото/Схемы» грузит сразу всю папку.
  Рядом с каждым файлом пометка «✅ в кэше» / «☁ не кэширован».
- Где лежит кэш: «⚙ Настройки» → блок «Состояние кэша» (число документов, листов, списков
  файлов, медиа, размер, дата последней синхронизации, путь к папке) + кнопка «🗑 Очистить кэш».

Данные приложения на Android: `user_data_dir` (`/sdcard/Android/data/org.ppu.ppupomoshnik/files`),
на десктопе: `./app_data`. Логи — `ppu.log` там же.

## Сборка APK

Только Linux. На Windows — WSL2 (команды в шапке `buildozer.spec`):

```bash
sudo apt update
sudo apt install -y git zip unzip openjdk-17 python3-pip python3-setuptools \
    autoconf libtool pkg-config zlib1g-dev libncurses5-dev libglib2.0-dev \
    libx11-dev libssl-dev cmake maven
pip3 install --user --upgrade pip cython buildozer

cp -r /mnt/d/Qoder/ppu_bot_TG_only/ppu_kivy_app ~/ppu_kivy_app   # credentials.json НЕ копируем
cd ~/ppu_kivy_app
buildozer android debug        # первая сборка качает SDK/NDK: 20–60 минут
# итог: bin/*-debug.apk
```

`credentials.json` в APK не зашивается — он всегда заводится через экран настроек
(или укладывается в папку приложения вручную).

## Отличия от бота

| Бот (`main3.py`) | Приложение |
|---|---|
| Пароль + `authorized_users.txt` | нет авторизации (распространяется среди своих) |
| `python-telegram-bot`, `httpx`, `gspread` | только `requests` + `google-auth` (меньше рецептов для p4a) |
| Кэш в памяти на 60 минут | кэш на диске, без срока давности; обновление — по кнопке |
| Спойлеры `||пароль||` | пароли в таблицах выводятся как `[ значение ]` |
| Разбиение длинных сообщений | прокрутка экрана |
